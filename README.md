O nosso projeto coletivo em C# envolve o funcionamento de uma biblioteca, aplicando os conceitos  de algoritmos de busca e seleção em C# na prática.

Criamos um algoritmo que utiliza Bobble Sort como seu algoritmo de ordenação e busca binária como algortmo de busca principal, já que o código possui listas ordenadas dos livros com suas propriedades,
como o autor, ano, ID(Identificação) e o título do livro, facilitando a busca e reduzindo a complexidade do código, dimimuindo o consumo de memória e acelerando o processo de busca geral dos livros.
